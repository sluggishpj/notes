# ES2025

## Duplicate named capturing groups(重复命名捕获组)

ES2025 之前，正则表达式中不能使用相同的[命名捕获组](./js-regular-expressions.md#组和范围)，否则会抛出错误。  
ES2025 开始，我们可以在不同的替代方案中使用相同的命名捕获组。例如：

```js
const regex = /(?<year>[0-9]{4})-[0-9]{2}|[0-9]{2}-(?<year>[0-9]{4})/
console.log('2025-01'.match(regex).groups)
// { year: '2025' }
console.log('01-2025'.match(regex).groups)
// { year: '2025' }
```

需要注意的是：目前该提案仅允许在不同的 `|` 或条件中复用命名捕获组，单个匹配中不能多次使用同一命名捕获组。

例如，下面的正则表达式是无效的：

```js
const regex = /(?<year>[0-9]{4})-[0-9]{2}-(?<year>[0-9]{4}))/
// SyntaxError: Invalid regular expression: /(?<year>[0-9]{4})-[0-9]{2}-(?<year>[0-9]{4}))/: Duplicate capture group name
```

## Set Methods(新增 Set 相关方法)

- `Set.prototype.intersection(other)` 交集
- `Set.prototype.union(other)` 并集
- `Set.prototype.difference(other)` 差集
- `Set.prototype.symmetricDifference(other)` 对称差集
- `Set.prototype.isSubsetOf(other)` 是否为子集
- `Set.prototype.isSupersetOf(other)` 是否为超集
- `Set.prototype.isDisjointFrom(other)` 是否为不相交集

### 示例

```js
const set1 = new Set([1, 2, 3, 4, 5])
const set2 = new Set([4, 5, 6, 7, 8])

console.log(set1.intersection(set2)) // Set(2) {4, 5}
console.log(set1.union(set2)) // Set(8) {1, 2, 3, 4, 5, 6, 7, 8}
console.log(set1.difference(set2)) // Set(3) {1, 2, 3}
console.log(set1.symmetricDifference(set2)) // Set(6) {1, 2, 3, 6, 7, 8}
console.log(set1.isSubsetOf(set2)) // false
console.log(set1.isSupersetOf(set2)) // false
console.log(set1.isDisjointFrom(set2)) // false

const set3 = new Set([1, 2, 3])
console.log(set3.isSubsetOf(set1)) // true
console.log(set3.isSupersetOf(set1)) // false
console.log(set1.isSupersetOf(set3)) // true
console.log(set3.isDisjointFrom(set1)) // false

const set4 = new Set([7, 8])
console.log(set3.isDisjointFrom(set4)) // true
```

## Regular Expression Pattern Modifiers(正则表达式模式切换)

允许在正则表达式的不同部分使用不同的匹配模式。

- `(?imsx-imsx:subexpression)` — Sets or unsets (using `-`) the specified RegExp flags for the subexpression.

```js
// (?-i:...) 表示在括号内的部分临时关闭不区分大小写的标志（即取消 i 标志的效果）
const re1 = /^[a-z](?-i:[a-z])$/i
re1.test('ab') // true
re1.test('Ab') // true
re1.test('aB') // false

// (?i:...) 表示在括号内的部分临时启用不区分大小写的标志（即添加 i 标志的效果）
const re2 = /^(?i:[a-z])[a-z]$/
re2.test('ab') // true
re2.test('Ab') // true
re2.test('aB') // false
```

## Import Attributes(导入属性)

允许在导入语句中指定额外的属性，例如：

```js
import json from "./foo.json" with { type: "json" };
```

> 拿到的 json 是对应的 JS 对象

> 作用之一：可以防止响应服务器意外提供不同的 MIME 类型，导致代码意外执行的情况，将提高安全性

### re-export statements

```js
export { val } from './foo.js' with { type: "javascript" };
```

### 与动态导入的结合

Import Attributes 也可以与动态导入一起使用

```js
import('foo.json', { with: { type: 'json' } })
```

## Iterator helpers(迭代器方法)

### `.map(mapperFn)`

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const result = naturals().map((value) => {
  return value * value
})

result.next() //  {value: 0, done: false};
result.next() //  {value: 1, done: false};
result.next() //  {value: 4, done: false};
```

### `.filter(filtererFn)`

filter 方法接受一个函数作为参数。它允许用户跳过那些不满足过滤函数条件的迭代值。

返回一个由原始迭代器中通过过滤函数测试的元素组成的迭代器。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const result = naturals().filter((value) => {
  return value % 2 === 0
})

result.next() //  {value: 0, done: false};
result.next() //  {value: 2, done: false};
result.next() //  {value: 4, done: false};
```

### `.take(limit)`

`take` 方法接受一个整数作为参数。它返回一个迭代器，该迭代器最多产生由底层迭代器生成的给定数量的元素。

简单来说，它会从原始迭代器中返回从索引 0 开始直到指定限制数量的项目。这是一种限制迭代器输出数量的方法。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const result = naturals().take(3)

result.next() //  {value: 0, done: false};
result.next() //  {value: 1, done: false};
result.next() //  {value: 2, done: false};
result.next() //  {value: undefined, done: true};
```

### `drop(limit)`

`drop` 方法接受一个整数作为参数。它返回一个迭代器，该迭代器会跳过由底层迭代器生成的前 n 个元素，其中 n 是指定的限制数量。

简单来说，它会从原始迭代器中返回从索引 n 开始的所有项目。这是一种从迭代器中排除前 n 个元素的方法。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const result = naturals().drop(3)

result.next() //  {value: 3, done: false};
result.next() //  {value: 4, done: false};
result.next() //  {value: 5, done: false};
```

### `flatMap(mapperFn)`

`flatMap` 方法接受一个函数作为参数。它会对原始迭代器中的每个元素应用映射函数，然后将所有结果“展平”为一个新的迭代器。

简单来说，它是 `map` 和 `flat` 方法的组合。首先，它会对每个元素应用映射函数，然后将所有结果“展平”为一个新的迭代器。

```js
const sunny = ["It's Sunny in", '', 'California'].values()

const result = sunny.flatMap((value) => value.split(' ').values())
result.next() //  {value: "It's", done: false};
result.next() //  {value: "Sunny", done: false};
result.next() //  {value: "in", done: false};
result.next() //  {value: "", done: false};
result.next() //  {value: "California", done: false};
result.next() //  {value: undefined, done: true};
```

### `.reduce(reducer [, initialValue ])`

类似于数组的 reduce 方法，它会遍历迭代器中的所有元素，并通过指定的函数将这些元素"归约"成单个值。每次迭代时，前一次计算的结果会作为下一次计算的输入之一。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const result = naturals()
  .take(5)
  .reduce((sum, value) => {
    return sum + value
  }, 3)

result // 13
```

> 初始值 3+0+1+2+3+4=13

### `toArray()`

`toArray` 方法会将迭代器中的所有元素收集到一个数组中。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const result = naturals().take(5).toArray()

result // [0, 1, 2, 3, 4]
```

### `forEach(fn)`

`forEach` 方法会对迭代器中的每个元素调用指定的函数。

```js
const log = []
const fn = (value) => log.push(value)
const iter = [1, 2, 3].values()

iter.forEach(fn)
console.log(log.join(', ')) // "1, 2, 3"
```

### `some(fn)`

`some` 方法会对迭代器中的每个元素调用指定的函数。如果至少有一个元素使得函数返回 true，则返回 true；否则返回 false。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const iter = naturals().take(4)

iter.some((v) => v > 1) // true
iter.some((v) => true) // false, iterator is already consumed.

naturals()
  .take(4)
  .some((v) => v > 1) // true
naturals()
  .take(4)
  .some((v) => v == 1) // true, acting on a new iterator
```

### `every(fn)`

`every` 方法会对迭代器中的每个元素调用指定的函数。如果所有元素都使得函数返回 true，则返回 true；否则返回 false。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

const iter = naturals().take(10)

iter.every((v) => v >= 0) // true
iter.every((v) => false) // true, iterator is already consumed.

naturals()
  .take(4)
  .every((v) => v > 0) // false, first value is 0
naturals()
  .take(4)
  .every((v) => v >= 0) // true, acting on a new iterator
```

### `find(fn)`

`find` 方法会对迭代器中的每个元素调用指定的函数。如果至少有一个元素使得函数返回 true，则返回该元素；否则返回 undefined。

```js
function* naturals() {
  let i = 0
  while (true) {
    yield i
    i += 1
  }
}

naturals().find((v) => v > 1) // 2
```

### `Iterator.from(object)`

`Iterator.from` 方法会将一个可迭代对象转换为一个迭代器。

```js
class Iter {
  next() {
    return { done: false, value: 1 }
  }
}

const iter = new Iter()
const wrapper = Iterator.from(iter)

wrapper.next() // { value: 1, done: false }
```

## `Promise.try`

`Promise.try` 方法会将一个函数转换为一个 Promise。如果函数执行成功，则返回一个 resolved Promise；如果函数执行失败，则返回一个 rejected Promise。

```js
Promise.try(() => {
  return 1
}).then((value) => {
  console.log(value) // 1
})
```

## `RegExp.escape`

`RegExp.escape(string)` 静态方法会转义字串中任何可能的正则[语法字符串](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Regular_expressions/Literal_character#description)，返回一个新的字串，该字符串可以安全地用作 `RegExp()` 构造函数的参数。

```js
RegExp.escape("Buy it. use it. break it. fix it.");
// "\\x42uy\\x20it\\.\\x20use\\x20it\\.\\x20break\\x20it\\.\\x20fix\\x20it\\."
RegExp.escape("foo.bar"); // "\\x66oo\\.bar"
RegExp.escape("foo-bar"); // "\\x66oo\\x2dbar"
RegExp.escape("foo\nbar"); // "\\x66oo\\nbar"
RegExp.escape("foo\uD800bar"); // "\\x66oo\\ud800bar"
RegExp.escape("foo\u2028bar"); // "\\x66oo\\u2028bar"
```

> REF：[MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/RegExp/escape)
